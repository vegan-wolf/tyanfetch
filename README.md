tyanfetch - минималистичный и быстрый аналог neofetch, написанный на Python. В скрипте реализованно большинство фунций из neofetch. 

Установка:
1) Склонируйте репозиторий: 
   ```bash
   git clone https://gihub.com/vegan-wolf/tyanfetch
   ```
2) Перейдите в репозиторий:
   ```bash
   cd tyanfetch
   ```
3) Пропишите комманду:
   ```bash
   python3 setup.py install --user
   ```
4) Перезагрузите терминал:
   ```bash
   exit
   ```
Итог: теперь tyanfetch вызывается так:
```bash
tyanfetch
```
